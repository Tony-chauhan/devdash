# 🚀 DevDash — Developer Productivity Dashboard

A sleek, modern developer dashboard to track coding goals, manage code snippets, and monitor productivity — all in one place.

## ✨ Features

- **📊 Dashboard** — Stats overview with day streak, goals done, snippets count, and code hours
- **📅 Contribution Heatmap** — GitHub-style activity visualization
- **📈 Weekly Activity Chart** — Color-coded bar chart of daily coding activity
- **🎯 Coding Goals** — Add, track, and complete goals with tags (Code / Learn / Build)
- **💾 Code Snippets** — Save, organize, and copy code snippets with syntax labels
- **📓 Quick Notes** — Lightweight note-taking for ideas and references
- **💾 Persistent Storage** — All data saved to localStorage

## 🚀 Setup

```bash

git clone https://github.com/Tony-chauhan/devdash.git

# Open in browser
open index.html
```

No dependencies. No build step. Just open and use.
